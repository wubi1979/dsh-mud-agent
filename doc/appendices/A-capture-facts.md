# 附录 A：抓包与语料事实

> **性质**：**实测事实**（E3 级证据，定义见附录 B）。MUD 侧（pkuxkx）实录，不随宿主换代失效；用于登录流程判据定稿（§8.15）、读窗口参数（§5.2）与语料校准（§13.4）。

## A.1 登录提示行原文（实录）

| 环节 | 原文 |
|---|---|
| 用户名提示（长形态，**判据唯一形态**） | `您的英文名字（要注册新人物请输入new。）：` |
| 用户名提示（短形态，**已不作判据**） | `您的英文名字：` |
| 密码提示（**判据唯一形态**） | `此ID档案已存在，请输入密码：` |
| 同名在线确认 | `您要将另一个连线中的相同人物赶出去，取而代之吗？(y/n)` |
| 用户名不存在（need-new，**用户名动态内嵌**） | `同意玩家须知并使用<用户名>创造一个新的人物，您确定吗(yes)？` |
| 用户名非法 | `对不起，你的英文名字只能用小写英文字母。` |
| 登录完成 | `目前权限：(player)` |
| 断线重连完成 | `重新连线完毕` |

**三条对判据的硬约束（§8.15 实测勘误）**

1. **同名在线确认句不含「同名 / 覆盖 / 替换」等关键词**（实录 2026-09-11）——按关键词集匹配必然漏匹配，必须**按原句匹配**。
2. **「欢迎来到」不可作成功句**：与建连横幅「欢迎来到北大侠客行」**撞车**，登录前即到达会误判成功；成功句只认 `目前权限：(player)` 与 `重新连线完毕`。
3. **提示判据收窄为单形态 + `^` 行首锚（`flags: 'm'`）**（实机 2026-10-03）：短形态 `您的英文名字：`、裸 `请输入密码：` 不再作判据（防聊天语句误触发）；need-new 句**内嵌动态用户名** ⇒ 判据用 `使用\S+创造` 桥接，`(yes)` 括号须转义；整窗按行 join 匹配，`^` 配 `'m'` 才是行首（无 `'m'` = 窗首，提示行在横幅后永不命中）。

## A.2 GA 节拍

- **GA 与命令 1:1**（实测 21/21）。
- **GA 延迟 1–602ms**，远小于投递静默窗口（`deliverQuietMs` 缺省 500ms 量级与 2s 级静默窗）——**GA 是可靠命令边界**（§3.4、§5.2 `gaCount` 判据依据）。
- 结论：`mud_send` 有 `cmd` 时的缺省判据 `gaCount: 1 + maxLines` 兜底因此成立（§8.7）。

## A.3 长程命令

- 例：`dz` —— 受理帧 GA + prompt 之后，**56 批 / 约 57s 无 GA 无 prompt**，完成句与末条推送**同块**到达。
- 结论：
  - **不能只靠 GA 判长命令结束**（`maxLines` 兜底与 `timeoutMs` 必须存在，§8.7）；
  - 长输出的**边界只能靠静默窗口**切分（§4.3 批次粒度与 TCP 块边界无关）。

## A.4 分页

- 每页**独立命令 + 独立 GA**；页尾是换行行 `== 未完继续 88% ==`，**不是 prompt**。
- 结论：分页判据不能依赖 prompt；翻页命令的归属与直发豁免属后置项（§17.3）。

## A.5 服务器不回显

- **服务器不回显命令**（含密码）——密码明文的泄漏面**只在本机**：画面回显、日志、上下文。
- 结论：这正是 §12.2 三道闸必须存在的理由（本地三条路径全封）；画面回显前缀（§5.3）只对**我方发送**打标。
